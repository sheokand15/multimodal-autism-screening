# A Multimodal Machine Learning Framework for Early Autism Screening

This repository implements a reproducible academic prototype with two **separate** tracks: (A) toddler questionnaire screening-trait label reconstruction and (B) a synthetic multimodal file-level benchmark. It does not provide clinical screening or diagnosis.

## Important scientific limits

- Dataset 1’s `Class/ASD Traits ` is exactly generated by `sum(A1..A10) > 3` in the supplied archive. The Q-CHAT score is excluded from predictors. Perfect results measure reconstruction of that rule, not independent autism detection.
- Dataset 2 metadata describes partially synthetic/augmented data and says it does not represent real individuals. Its four labels are not clinically validated.
- Dataset 2 images cannot be joined to index rows: the index lists PNG files, but the archive contains differently named JPGs. Image modeling is disabled. Audio, motion, and physiology are linked by exact sample-ID paths, although participant provenance and synchronization are not independently authenticated.
- Source licensing terms are unclear in the supplied metadata. Raw archives are not copied into this repository.

## Requirements

Python 3.10+; packages in `requirements.txt`. The implementation uses NumPy and Pillow for audit/features/models. Streamlit is only needed for the optional UI. The baseline audit, training, and tests ran here; the Streamlit UI was not launched because Streamlit is unavailable in the current runtime. No scikit-learn, PyTorch, pretrained weights, or network access is required for the baseline workflow.

Place the supplied ZIP files in a data directory. By default, scripts use the user-provided location `E:\College\7th Semester\Project\Data Set`. Set `ASD_DATA_DIR` to another directory if needed.

### PowerShell setup and reproduction

```powershell
python -m pip install -r requirements.txt
$env:ASD_DATA_DIR = 'E:\College\7th Semester\Project\Data Set'
$env:PYTHONPATH = '.'
python -m src.data.audit_datasets
python -m src.train_experiments
python -m unittest discover -s tests -v
```

Run the optional interface after training:

```powershell
streamlit run app.py
```

The audit creates fixed-seed track manifests and reports. Training writes small JSON model artifacts, evaluation metrics, and an experiment registry under `artifacts/`. The original ZIP files remain unchanged in the external data directory. Running training again regenerates artifacts and uses the saved split assignments.

## Repository layout

- `src/data/`: archive audit and deterministic split assignment.
- `src/features/`: questionnaire and modality feature extraction.
- `src/models/`: NumPy-only classifiers and training-only standardization.
- `src/evaluation/`: classification metrics.
- `src/inference/`: questionnaire and multimodal file inference.
- `src/train_experiments.py`: validation-selected baselines and fusion prototypes.
- `tests/`: reproducibility, scoring, mapping, leakage, shape, and inference checks.
- `configs/project.json`: seed, split, predictors, target, and modality policy.
- `data/manifests/`: immutable-by-convention sample assignments and path audit.
- `reports/`: dataset audits, fusion design, limitations, and final report.
- `artifacts/`: model JSON, metrics, coefficients, and experiment registry.

## Model behavior

Dataset 1 inference accepts the ten already-binarized item codes and returns the transparent score-rule output plus a separately identified logistic-model prediction. The model probabilities are uncalibrated and should not be used for decisions.

Dataset 2 inference accepts any subset of WAV, motion JSON, and physiology CSV files. Branch predictions are returned for available modalities and late fusion averages only those branches. Early fusion is available when all three supported modalities are provided. Image files are not accepted. Combining files assumes the inputs belong to one sample; the prototype cannot verify identity or synchronization.
