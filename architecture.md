# System Architecture

## Purpose and scope

This repository is a research prototype for auditing supplied datasets and demonstrating two separate machine-learning workflows. The datasets have different targets and data characteristics, so they are evaluated as separate tracks rather than combined. This is not a clinical screening or diagnostic system.

## High-level architecture

```text
Source archives
  -> Dataset audit and deterministic manifests
      -> Track A: questionnaire items A1-A10
          -> transparent score rule
          -> logistic regression and CART decision tree
      -> Track B: synthetic multimodal files
          -> audio / motion / physiology feature extraction
          -> unimodal classifier branches
          -> early feature fusion (concatenate, then classify)
          -> late decision fusion (average branch probabilities)
  -> held-out evaluation and saved artifacts
  -> optional Streamlit research demonstration
```

## Components

1. **Audit and manifests** — `src/data/audit_datasets.py` checks archive contents, schemas, labels, missingness, duplicates, and modality paths. It creates deterministic train/validation/test assignments using seed 42.
2. **Feature extraction** — `src/features/extract.py` converts questionnaire answers and supported modalities into fixed-size tabular matrices. Track B uses 10 audio, 63 motion, and 21 physiology summary features; these are engineered features, not learned neural embeddings.
3. **Models** — `src/models/classical.py` implements multinomial logistic regression and a small CART classifier with NumPy.
4. **Fusion** — `src/fusion/strategies.py` concatenates modality feature blocks for early fusion and averages modality class probabilities for late fusion.
5. **Evaluation** — `src/train_experiments.py` selects settings on validation data, evaluates on the held-out test set, and saves metrics and model artifacts. Preprocessing is fit on training rows only.
6. **Demo** — `app.py` provides an optional Streamlit interface and displays research outputs with limitations.

## Track A: questionnaire label reconstruction

The target `Class/ASD Traits ` is exactly generated by whether the sum of A1-A10 exceeds 3. The score and target columns are excluded from learned-model predictors. Because the target is a deterministic function of the same inputs, high accuracy measures label-rule reconstruction, not independent autism detection.

## Track B: multimodal benchmark

The supplied index contains 100 samples. Audio, motion, and physiology files resolve by exact sample-ID paths. Provider metadata describes this dataset as partially synthetic/augmented and not representative of real individuals. Image paths do not map to the supplied image filenames, so images are excluded. Inference with multiple files assumes they belong to one synchronized sample; the prototype cannot verify that assumption.

## Fusion details

- **Early feature fusion:** concatenate audio, motion, and physiology feature vectors, then fit one classifier on the joint representation.
- **Late decision fusion:** train one classifier per modality and take the equal-weight mean of their class-probability vectors.

The current implementation does not contain a Transformer, attention layer, learned gating network, pretrained foundation model, or autonomous AI agent. Use those terms only if a future version implements and evaluates such components.

## Limitations

Dataset 1's target is derived from its questionnaire inputs. Dataset 2 is small, synthetic per its provider, and has only 15 held-out test samples. Its labels are not clinically validated. The image mapping, participant independence, provenance, and synchronization cannot be confirmed from the supplied files. These constraints prevent clinical or real-world generalization claims.
